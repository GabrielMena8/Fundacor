# Fundacor Sanity Studio

Minimal Sanity Studio scaffold for `fundacor`.

How to use:

1. Install dependencies:

```powershell
cd studio
npm install
```

2. Start local studio:

```powershell
npm run dev
```

3. Deploy to Sanity-hosted studio:

```powershell
npm run deploy
```

You must have access to the Sanity project `ut4uykcs`.
